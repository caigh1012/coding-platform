## 二、后端问题总结

### 2.1、短信验证码

由于政策原因，阿里云和腾讯云的短信云产品不支持个人认证，只能企业认证才可以开通，所以这里未接入短信验证码。

由于未接入短信验证码也就没有接入腾讯滑块等图形验证码

### 2.2、图形验证码接口

第一点：

由于未接入短信验证码，所有尝试接入 hutool 的图形验证码

第二点：

图形验证码接口为get请求时并且返回时设置请求头为 `Content-Type: image/png` ，返回的是一张图片。前端使用 img 的 src 进行处理才可以，但是这样无法存储图形验证码的 code

第三点：

如果使用 redis 来存储 code 就是导致一个问题，用户如果恶意或者黑客攻击不断调取获取图形验证码接口就会导致 redis 服务器压力过大，性能和流量上的消耗。

一般来说，是需要对接口进行 ip 访问次数限制，例如：比如一分钟内只能使用5次，防止一直刷接口

第四点：

由于这里只是可以模拟图形验证码可用，这里返回的图片采用 base64 形式，并将 redis 存储图形验证码的 code 的 key 发送给前端。
